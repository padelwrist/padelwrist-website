Deuce formats · Reviewed 27 August 2026

Golden Point, advantage or Star Point?

All three formats use the familiar score up to 40-40. The difference is how they end a close game.

Reviewed against current FIP rules and the 2026 Star Point announcement.

Traditional advantage

At 40-40 the score is deuce. Win the next point and you have advantage. Win again and you take the game. Lose the advantage point and the score returns to deuce. There is no fixed maximum number of deuce cycles.

Golden Point

Golden Point removes repeated advantage play. At deuce, a deciding rally settles the game. The exact receiving procedure depends on the rules being used, so tournament or league regulations should be checked rather than assumed from a social format.

Star Point

From 2026, FIP introduced Star Point across Premier Padel, CUPRA FIP Tour, FIP Promises and FIP Beyond. It keeps limited advantage play, then uses a deciding point at the third deuce. It is deliberately a middle ground between unlimited advantage and an immediate deciding point.

Why the distinction matters

Deuce format changes both match feel and duration. Advantage can produce long games. Immediate deciding-point scoring makes duration more predictable. Star Point preserves some advantage tension while preventing a game from cycling through deuce indefinitely.

It also changes pressure. Under Golden Point, one loose return at 40-40 ends the game immediately. With advantage, a pair has more room to recover because a single point normally creates advantage rather than ending the game. Star Point sits between those extremes, so players still experience advantage points but know the game cannot run indefinitely.

What should club players use?

Whatever the organiser specifies, or whatever all four players agree before the match. There is no benefit in discovering halfway through the first deuce that two players expected advantage and two expected a deciding point.

If you are playing casually, choose based on the session. Advantage suits a traditional full match when time is flexible. Golden Point is useful when court time is tight. Star Point can be a good compromise if everyone understands it. The important part is consistency: the scoreboard, server and receiving side all need to follow the same rule from the first deuce onwards.

How this affects scorekeeping

A scorekeeper cannot infer the deuce rule from 40-40 alone. The selected format determines whether the next rally produces advantage, ends the game or moves the game towards a later deciding Star Point. Set the rule before play starts so the scoring flow matches what the four players expect.
