PadelWrist release history

Changelog

PadelWrist keeps evolving around one idea: make scoring effortless during the match, then make the result more useful afterwards. Here is what changed in every public release from 1.0 to 1.5.

Current release

Version 1.5

PadelWrist becomes available in Spanish across the full match experience.

  • Spanish localisation across iPhone and iPad
  • Spanish support throughout the Apple Watch app
  • Localised Insights, Match History, post-match views and live-match screens
  • Spanish Live Activities and Dynamic Island content
  • Localised Apple Health permission messaging
  • Spoken scoring available in Spanish
  • Spanish App Store localisation and release presentation

Match intelligence

Version 1.4

Version 1.4 made completed matches much more useful and brought the live score to more places on iPhone.

  • Dedicated Insights tab with performance trends, recent form and player analysis
  • Compare results over time and across match formats
  • Partner and opponent records
  • Post-match milestones, winning streaks and notable form
  • Search and filter Match History by date, format, result, players and more
  • Add match type, playing side and private notes
  • Live Activities and Dynamic Island support for the current match
  • New Getting Started experience
  • Improved Insights charts, navigation, accessibility and low-data presentation

Explore PadelWrist Insights →

Connected matches

Version 1.3

Version 1.3 expanded PadelWrist beyond scoring with sharing, cloud continuity, workouts and more flexible match rules.

  • Share live matches using a simple Match Code
  • Record padel matches as workouts in Apple Health
  • Private iCloud sync for Match History and saved players
  • Player Intelligence and performance insights
  • Polished match result cards for sharing
  • Advantage scoring
  • Golden Point scoring
  • Star Point scoring
  • Match Tie-Break options
  • Accessibility improvements across iPhone, iPad and Apple Watch
  • Further match sync, recovery and reliability improvements

Explore match sharing →

Cross-device polish

Version 1.2

A major refinement release focused on making the core scoring experience smoother and more consistent across every supported device.

  • Redesigned Play experience across iPhone and iPad
  • Refined iPhone and iPad live scoring layouts
  • Refined and standardised Apple Watch scoring UI
  • Improved match setup and configuration
  • Clearer match completion and score correction flows
  • Improved Match History and Settings accessibility semantics
  • Better landscape and compact-height layouts
  • Stronger session reconciliation, recovery and synchronisation
  • Further accessibility and interface polish

Reliability update

Version 1.1

The first update concentrated on the reliability issues and interface details discovered immediately after launch.

  • Fixed intermittent Start Match state issues
  • Restored serving information in Fixed Points matches
  • Improved Standard Match score editing and set validation
  • Improved multi-device live-match synchronisation
  • Landscape layout and alignment fixes
  • General stability and release polish

Initial release

Version 1.0

The first public release established PadelWrist as a native Apple Watch-first padel scorekeeper with companion experiences on iPhone and iPad.

  • Live padel scoring on Apple Watch
  • Standard Match scoring
  • Fixed Points scoring for Americano, Mexicano and similar social formats
  • iPhone and iPad match setup and companion use
  • Points, games, sets and serving information
  • Spoken score announcements
  • Undo and score correction
  • Pause and resume support
  • Saved players and Match History
  • Multi-device match continuity and recovery
  • No PadelWrist account required
