Rules & scoring · FIP rules reviewed 18 August 2026

The wrong player has served. Do you replay the points?

No. The 2026 FIP rules preserve the points already played. The correction depends on whether the error is discovered during the game or only after the game has finished.

If the mistake is discovered during the game

The player who should have been serving takes over as soon as the error is discovered. All points won before the error was identified remain valid.

The current FIP rule also says that if there had been a single service fault before the error was discovered, that fault is not carried over to the correct server.

If the whole game finishes before anyone notices

The game score still stands. Instead of reconstructing the original rotation, the altered order of service remains in place until the end of that set.

At the beginning of the next set, each pair can choose again which partner serves first, so the order can be reset there.

What if the right player serves from the wrong side?

That is a different error. If a serve is inadvertently made from the wrong side, the position is corrected as soon as the mistake is discovered. Points already played remain valid.

In this situation, if the server had already made a first-service fault, that fault does count, so only the second serve remains.

Why the two fault rules are different

The 2026 FIP text treats a wrong serving side and a wrong server as separate mistakes. For a wrong side, an existing first-service fault is retained. For a player serving out of turn, a single service fault before discovery is disregarded when the correct server takes over.

That distinction is easy to miss, which is one reason service-order arguments become confusing during social matches.

What about the receiving order?

The receiving pair also establishes an order for the set. Receiving-order errors are governed separately from service-order errors, so do not assume the wrong-server remedy automatically applies to the receivers.

We cover the full serving and receiving sequence in the padel service rules.

Quick reference

Wrong player, noticed mid-game: correct server takes over; existing points stand; a single previous service fault is disregarded.

Wrong player, noticed after the game: points and game stand; altered service order continues for the rest of the set.

Correct player, wrong side: correct the side; points stand; an existing first-service fault still counts.

Source

Checked against the International Padel Federation's Rules of Padel, review of application 1 January 2026, particularly Rule 6 on the serve.
